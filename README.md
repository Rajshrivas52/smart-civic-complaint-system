# AI-Enabled Smart Civic Complaint & Issue Management System

This is a real-world CSE/Data Science major project. 
It is a centralized digital system for reporting, managing, tracking, analyzing, and resolving civic complaints using an AI-enabled approach.

## Structure
- `frontend/`: React frontend
- `backend/`: Node.js + Express backend
- `ai-service/`: Python FastAPI service for ML models
- `database/`: Database scripts and schemas
- `docs/`: Project documentation
